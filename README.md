# トリアージ台帳（転記専用）

札幌市立病院 救命救急センターの救急隊ダッシュボードから患者情報を紙の台帳様式に転記・印刷するためのツールです。

## できること

- QRコード／テキスト／手入力から患者情報を取り込む
- 判定（応需・不応需、理由など）を追加入力する
- 紙の台帳フォーマット（A4）に整形して画面表示する
- ブラウザの印刷機能で印刷する

## データの取り扱い

本ツールは、入力されたデータをブラウザのメモリ上にのみ保持します。印刷後にタブを閉じるとデータは完全に消失します。

**データが保存されない場所：**
- 外部サーバ・クラウドサービス
- ブラウザストレージ（localStorage / sessionStorage / IndexedDB / Cookie）
- 端末のローカルディスク

**外部との通信：**
- 初回ロード時のみ：アプリ本体（HTML/CSS/JS/アイコン）、絵文字画像（Twemoji）、QRコード解析ライブラリ（jsQR）の取得
- 稼働中：外部への通信は一切発生しません（入力・印刷時を含む）

ソースコードは GitHub 上で完全に公開されており、どなたでも監査可能です。

## 運用フロー

1. アプリを開く（PC・タブレット・スマホのいずれでも可）
2. 「🆕 新規患者」から入力モードを選択：
   - **📷 QRコードを貼り付け** - 救急隊QRをスクリーンショットでコピー後、Ctrl+V
   - **📋 テキスト貼り付け** - 救急システムのコピーテキストを貼り付け
   - **✍️ 手入力** - 一から入力
3. 必要項目を追加入力（判定・転帰など）
4. 以下のいずれかのボタン：
   - **➕ 一覧に追加** - メモリ内の患者一覧に追加（後でまとめて印刷）
   - **🖨️ 今すぐ台帳を生成** - その場で台帳を表示・印刷
5. シフト終了時：
   - **🖨️ 全患者の台帳を一括生成** で一覧を全印刷
   - 印刷完了後、タブを閉じてデータを破棄

## デプロイ

GitHub Pages で `https://<account>.github.io/<repo>/` にホスティングします。

```bash
# ローカルで動作確認する場合（Pythonの簡易HTTPサーバ）
cd triage-transcribe-static
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## セキュリティに関する補足

本ツールは **札幌市情報セキュリティポリシー** および **札幌市立病院 情報セキュリティ遵守事項** に対応することを意図して設計されています：

- 外部クラウドへの患者情報の保存・送信は行いません
- 端末へのデータ保管も行いません
- 既承認済みの救急隊ダッシュボードの情報を紙に印刷するための中間フォーマッタとして機能します
- 印刷された紙は従来通り院内の紙記録として保管してください
