# トリアージ台帳（転記専用版・B案構成）

札幌市立病院 救命救急センター向け、既承認の救急隊ダッシュボードの情報を紙の台帳様式に転記・印刷するためのツールです。

## 設計の要点（情報セキュリティ対応）

本アプリは **外部サービスへの保存・ローカルディスクへの保存を一切行わない** 転記ツールとして設計されています。

### やっていること

- QRコード／テキスト／手入力から患者情報を受け取る
- 受付時の判定（応需/不応需、理由など）を追加入力する
- 紙の台帳フォーマット（A4）に整形して画面表示する
- ブラウザの印刷機能で印刷する

### やっていないこと

- GitHub／外部サーバへの送信・保存（**完全削除**）
- `localStorage` / `sessionStorage` / IndexedDB への患者データ保存（**完全削除**）
- Cookie への患者データ保存（**完全削除**）
- 患者データのネットワーク送信（HTMLロード以外の外向き通信なし）

患者データは JavaScript のメモリ変数（`App.records`）のみに保持され、以下のタイミングで **完全に消失** します：
- ブラウザタブを閉じたとき
- ページをリロードしたとき
- ブラウザがクラッシュしたとき
- 端末の電源を切ったとき

Service Worker はアプリの静的ファイル（HTML/CSS/JS/アイコン）のみキャッシュし、患者データは一切キャッシュしません。

## 通信

初回のアプリロード時のみ以下の通信が発生します：

| 通信先 | 用途 | 患者データの送信 |
|---|---|---|
| `gateofzen.github.io` （GitHub Pages） | HTML/CSS/JS/アイコンのダウンロード | **なし** |
| `cdn.jsdelivr.net` | Twemoji、jsQR ライブラリのダウンロード | **なし** |

**一度ロード後は、Service Worker のキャッシュで動作するため追加の通信は発生しません。** 患者情報を入力・編集する過程で外部への通信は一切発生しません（ブラウザの開発者ツール「ネットワーク」タブで確認可能）。

## 運用フロー

1. アプリを開く（PC・タブレット・スマホのいずれでも可）
2. 「🆕 新規患者」の下から入力モードを選択：
   - **📷 QRコードを貼り付け** - 救急隊QRをスクリーンショットでコピー後、Ctrl+V
   - **📋 テキスト貼り付け** - 救急システムのコピーテキストを貼り付け
   - **✍️ 手入力** - 一から入力
3. 必要項目を追加入力（判定・転帰など）
4. 以下のいずれかのボタン：
   - **➕ 一覧に追加** - メモリ内の患者一覧に追加（後でまとめて印刷）
   - **🖨️ 今すぐ台帳を生成** - その場で台帳を表示・印刷
5. シフト終了時：
   - **🖨️ 全患者の台帳を一括生成** で一覧を全印刷
   - 印刷完了後、タブを閉じてデータを破棄

## デプロイ

GitHub Pages で `https://<account>.github.io/<repo>/` にホスティングします。

```bash
# ローカルで動作確認する場合（Pythonの簡易HTTPサーバ）
cd triage-transcribe-static
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## セキュリティに関する補足

本ツールは **札幌市情報セキュリティポリシー** および **札幌市立病院 情報セキュリティ遵守事項** に対応することを意図して設計されています：

- **外部クラウドへの保存禁止** → 保存機能自体を実装していません
- **非公開情報の外部入力禁止** → 入力された情報は外部に送信されません
- **端末へのデータ保管禁止（原則ファイルサーバ）** → ブラウザストレージも使用しません

本ツールは、既承認済みの救急隊ダッシュボードの情報を「紙に印刷する」ための中間フォーマッタとしてのみ機能します。印刷された紙は従来通り院内の紙記録として保管してください。
